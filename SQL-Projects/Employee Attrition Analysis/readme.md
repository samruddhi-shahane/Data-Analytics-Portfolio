## Employee Attrition Analysis

## Project Overview

This project analyses employee attrition using SQL.
The objective is to answer business questions related to workforce distribution, employee turnover, salaries and promotion eligibility.

## Business Problem

The HR department wants to understand:

-Employee attrition
-Department performance
-Job role distribution
-Salary trends
-Promotion eligibility
-Workforce demographics
